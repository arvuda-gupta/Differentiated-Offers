A lean, product-based team to deliver the Differentiated Offers AI Platform. Sized for a POC with a clear path to scaling headcount into Phase 2 and 3 as the product proves value.

## Team Philosophy

Small, accountable, cross-functional. Every person owns a clear slice of the product. No hand-offs between a "business team" and a "tech team" - the team ships together. The commercial domain knowledge lives inside the squad, not in a separate stakeholder layer.

## Phase 1 Team (POC)

5 people. Enough to ship the agentic loop and run a real pilot with commercial teams.

| Role | Responsibility | FTE |
| --- | --- | --- |
| **Product Owner** | Owns the product vision and backlog. Runs pilot team feedback loops. Defines what gets built and in what order. Single decision-maker on scope trade-offs. | 1 |
| **AI / Agent Engineer** | Builds the agent layer - Orchestrator, Discovery Agent, Concept Validation Agent. Owns the LangGraph (or equivalent) orchestration framework. Responsible for agent tool design and prompt architecture. | 1 |
| **Fullstack Engineer** | Builds the Workspace UI for Stages 1 and 2. Keeps it simple - the UI should feel lighter than an Excel file, not heavier. Owns the MVP card builder in Stage Ensure orchestrator management in backend | 1 |
| **Commercial Domain Expert** *(embedded from Syngenta commercial team)* | The bridge between the product and the field. Validates agent outputs against real commercial judgment. Seeds and QA's the Needs Bank and Offer Bank. Runs the pilot team onboarding. Part-time in Phase 1, increasing in Phase 2. | 0.5 |
| QA | Need to Validate E2E testing before Phase 2 | 0.5 |

**No dedicated QA (Can be Shared), no dedicated DevOps, no separate data engineer in Phase 1.** Engineers own their own quality. Infrastructure is AWS-managed. Data import is a one-time script, not a pipeline team.

## Phase 2 Additions (Scaling)

3 additions when the POC proves value and data volumes justify it.

| Role | Why added at Phase 2 |
| --- | --- |
| **Second AI / Agent Engineer** | Market Intelligence Agent and Scaling Agent run continuously in the background. Enough complexity to warrant a second agent engineer while the first continues evolving the core loop. |
| **Commercial Domain Expert (second)** | Rollout to 5-8 teams needs more domain coverage. One expert per region cluster (Oceanic + Continental / South East + Mediterranean). |

## Phase 3 Additions (Enterprise)

| Role | Why added at Phase 3 |
| --- | --- |
| **Platform / DevOps Engineer** | Pan-EU rollout, RBAC, audit logs, and CRM integration need dedicated infrastructure ownership. |
| **Analyst** | Advanced analytics layer (offer lifetime value, % of sales attribution) needs someone who owns the Superset dashboard and the reporting models. |

## What This Team Does Not Need

- A separate "AI strategy" role - strategy is owned by the PM
- A scrum master - the team is small enough to self-organise
- A dedicated UX designer in Phase 1 - the Frontend Engineer owns UX with commercial domain input. Add a designer in Phase 2 if the pilot reveals real UX debt.
- A project manager - the build plan is the backlog, the PM runs it

## Governance and Reporting

| Touchpoint | Frequency | Who |
| --- | --- | --- |
| Team standup | Daily (async) | Full squad |
| Pilot team feedback session | Bi-weekly | P + Commercial Domain Expert + pilot team reps |
| Phase review and go/no-go | End of each phase | P + leadership |
| Architecture decisions | As needed (ADR logged in Confluence) | Engineers |
